# Native physics examples

Open the `.diagramtex` files in DiagramTeX. Both examples use editable basic shapes.

- Figure 1: pendulum, 37 shapes (lines, arcs, ellipses and labels).
- Figure 3: cylindrical geometry, 20 shapes. The outer annulus is a compound region with a transparent hole; the central cross-section is an ellipse. Both use native pattern fills, adjustable through Fill → Pattern.

The preview PNGs show the examples in the app. The older stroke-by-stroke cylinder remains a separate whiteboard in the browser where it was created.
